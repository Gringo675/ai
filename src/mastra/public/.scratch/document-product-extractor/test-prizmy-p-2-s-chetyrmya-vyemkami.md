* **Надежность:** наработка до первого отказа призм должна составлять 2500 измерений при вероятности безотказной работы $P^* = 0,8$.
* **Внешний вид и защита:**
  * Необработанные поверхности призм типа II должны быть окрашены.
  * На поверхности призм не должно быть трещин, раковин, посторонних включений и других дефектов.
  * Острые кромки призм должны быть притуплены.
  * Внутренние напряжения у призм должны быть устранены.
  * Призмы должны быть размагничены.
* **Комплектность:** комплект призм состоит из двух призм. По заказу потребителя допускается не укомплектовывать призмы.
* **Гарантийные обязательства:** гарантийный срок — 12 месяцев со дня ввода в эксплуатацию.

#### 3. Методы испытаний

* **Поверка параллельности призматических выемок основанию и боковым граням:** производится на поверочной плите (0-го класса по ГОСТ 10905-75) с помощью отсчетного устройства (цена деления $\le 0,001$ мм), штатива (тип III-I по ГОСТ 10197-70) и образцовых цилиндрических валиков по всем четырем призматическим выемкам. При поверке параллельности выемок боковым граням валик закрепляется специальным хомутиком.
* **Поверка симметричности расположения выемок:** призму через промежуточный образцовый валик прижимают к штативу, наконечник отсчетного устройства устанавливают перпендикулярно к грани призматической выемки. Отклонение равно 0,35 разности отсчетов. Поверка проводится по всем четырем выемкам.
* **Поверка взаимной перпендикулярности боковых граней:** производится с помощью отсчетного устройства, установленного на «нуль» по поверочному угольнику (0-го класса по ГОСТ 3749-77).
* **Шероховатость:** определяется визуальным сравнением с образцами шероховатости по ГОСТ 9378-75.
* **Размагниченность:** проверяется с помощью прибора типа ФП-1.

---

#### 4. Маркировка, упаковка, транспортирование и хранение

* **Маркировка:** на торцах каждой призмы должны быть нанесены:
  * товарный знак предприятия-изготовителя;
  * обозначение типоразмера и класс призмы;
  * порядковый заводской номер, общий для пары призм в комплекте;
  * год выпуска;
  * номер ГОСТ 5641-66.
* **Консервация и упаковка:** поверхности призм без антикоррозионного покрытия промываются обезжиривающей жидкостью, подвергаются консервации по ГОСТ 13168-69, обертываются бумагой, не впитывающей смазку, и упаковываются комплектами. Для транспортирования призмы упаковываются в деревянные ящики по ГОСТ 15623-79, выложенные водонепроницаемым материалом.
* **Сопроводительная документация:** каждый комплект сопровождается документом (паспортом), подтверждающим соответствие требованиям стандарта.
* **Условия хранения:** призмы должны храниться в сухих отапливаемых помещениях, воздухом без агрессивных примесей.
