### ТРЕБОВАНИЯ К ФОРМАТАМ ВЫХОДА

---

#### 1. ФОРМАТ 1: HTML ДЛЯ ЧЕЛОВЕКА (Human-Friendly HTML)

Сформируй самостоятельный HTML-документ/фрагмент, предназначенный для чтения человеком и печати.

**Требования к форматированию:**

1. **Визуальная и структурная точность:** Максимально точно воспроизведи структуру оригинального ГОСТа (заголовок, грифи, вводная часть, разделы, подразделы, пункты, примечания, приложения).
2. **Семантика HTML5:** Используй чистые семантические теги (`<h1>`-`<h6>`, `<p>`, `<ul>`, `<ol>`, `<li>`, `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`, `<sup>`, `<sub>`).
3. **Таблицы:**
   - Верстай таблицы с использованием `colspan` и `rowspan` для точного воспроизведения многоуровневых шапок и объединенных ячеек.
   - Добавь базовый лаконичный CSS (в теге `<style>`), чтобы таблицы имели четкие границы (border), комфортные отступы (padding) и корректное выравнивание текста.
4. **Сноски, формулы и примечания:** Оформляй верхние и нижние индексы через `<sup>` и `<sub>`. Примечания и формулы выделяй отступами или блок-цитатами для читаемости.

---

#### 2. ФОРМАТ 2: ГИБРИДНЫЙ МАРКДАУН ДЛЯ LLM (LLM-Optimized Markdown + HTML)

Сформируй очищенный документ, предназначенный для подачи в контекст языковых моделей (LLM / RAG-систем).

**Требования к форматированию:**

1. **Заголовки и структура текста:**
   - Используй четкую иерархию Markdown (`#`, `##`, `###`, `####`).
   - Обычный текст, параграфы и нумерованные/маркированные списки оформляй в стандартном Markdown.
2. **Сложные таблицы (Критически важно):**
   - Все таблицы верстай исключительно в формате **HTML (`<table>`)**. Не используй Markdown-сетку (`|---|---|`), так как она разрушает вложенные шапки.
   - Обязательно сохраняй атрибуты `colspan` и `rowspan` в тегах `<th>` и `<td>`.
3. **Максимальная очистка от токенового шума:**
   - Полностью УДАЛИ все стили (`style="..."`), классы (`class="..."`), идентификаторы (`id="..."`).
   - Не используй теги-обертки (`<div>`, `<span>`, `<font>`).
   - Не используй теги горизонтальных линий (`<hr>`).
4. **Сохранность данных:** Ни в коем случае не сокращай текст, не убирай допуски, числа, единицы измерения, сноски и диапазон значений.

      }

    </style>

  </body>

<!-- === КОНЕЦ: HTML ДЛЯ ЧЕЛОВЕКА === -->
