# Category Characteristics and Content Generation Context

Система автоматической генерации структурированных технических характеристик и описаний для категорий каталога измерительного инструмента на основе нормативно-технической документации и каталожных параметров.

## Language

### Core Entities

**Category Data**:
Исходные структурированные данные категории из API, включающие метаданные категории, нормативные документы (ГОСТ, ГРСИ) с текстами и доступные свойства товаров каталога (`availableProps`).
_Avoid_: raw data, category dump

**Category Characteristics**:
Итоговый чистый HTML-фрагмент со структурированными техническими параметрами (заголовки с `doc-viewer-link`, таблицы `<table>`, списки `<ul>`), отображаемый в карточке категории каталога.
_Avoid_: description, specs, category text

**Standard Document**:
Официальный государственный стандарт (ГОСТ, ГОСТ Р, ОСТ, ТУ), регламентирующий технические условия и параметры группы измерительных инструментов.
_Avoid_: standard, norm, gost file

**Register Document**:
Запись Государственного реестра средств измерений (ГРСИ) с прикрепленными файлами Описания типа (`file_ot`) и Методики поверки (`file_mp`).
_Avoid_: grsi record, verification doc

**Type Description**:
Официальный метрологический документ ГРСИ («Описание типа»), содержащий конкретные метрологические и технические характеристики, схемы и таблицы для утвержденного типа СИ.
_Avoid_: passport, manual

**Verification Procedure**:
Официальный нормативно-методический документ («Методика поверки»), описывающий операции, средства и условия поверки средства измерений.
_Avoid_: calibration doc, mp file

**Document Extraction**:
Выжимка метрологических параметров, таблиц и диапазонов из текста конкретного документа, содержащая целевой тип инструмента (`toolType`), бренд производителя (`brand`), и **все** данные, относящиеся к целевой категории (без отсечения вариантов и значений параметров внутри категории); отсекаются только части, относящиеся к иным категориям.
_Avoid_: summary, parsing result

**Tool Type**:
Конкретное функционально-конструктивное исполнение или подтип измерительного инструмента в рамках категории, для которого произведено извлечение данных из документа (например, «Штангенциркули цифровые ШЦЦ» в категории «Штангенциркули»).
_Avoid_: subcategory, group, device kind

**Instrument Brand**:
Каноническое краткое наименование бренда/производителя измерительного инструмента (например, ЧИЗ, КировИнструмент, СТИЗ), однозначно нормализованное с исключением устаревших или альтернативных алиасов.
_Avoid_: manufacturer string, vendor name

**Fallback Research**:
Синтезированная сводка технических параметров и типоразмеров, формируемая агентом-исследователем через веб-поиск и свойства товаров каталога при отсутствии привязанных документов с текстом.
_Avoid_: web scrap, fallback data

**Characteristics Policy**:
Формализованный набор правил разметки, запретов на галлюцинации и критериев валидации HTML, передаваемый копирайтеру и судье.
_Avoid_: system prompt, instructions
