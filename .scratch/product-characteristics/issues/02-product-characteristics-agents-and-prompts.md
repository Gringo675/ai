# Issue 02: Агенты, промпты и политика генерации характеристик товара

## Проблема
Существующие агенты категории (`categoryCharacteristicsCopywriterAgent`, `categoryCharacteristicsJudgeAgent`) оптимизированы под сжатие документов в масштабе всей категории (сводные таблицы всех типоразмеров, строгие правила консолидации заголовков). Для товаров требуется отдельный набор агентов и промптов, сфокусированных на параметрах единичной модификации, работающих на быстрых и экономичных моделях семейства Flash-Lite.

## Требования к реализации
1. **Политика характеристик товара (`prompts/productCharacteristicsPolicy.md`)**:
   - Описание правил формирования HTML для конкретной карточки товара.
   - Заголовки со ссылками на применимые ГОСТ/ГРСИ (класс `doc-viewer-link`, `target="_blank"`).
   - Гибкость представления: компактная таблица `<table>` (с классами `ta-start`/`ta-end`) при наличии матрицы параметров, либо маркированный список `<ul>`, либо параграфы `<p>`.
   - Запрет вывода параметров посторонних моделей/размеров из переданного документа.
   - Правила учета действующих характеристик товара (сохранение артикулов/комплектации при непротиворечии).
   - Роль характеристик категории: передаются **исключительно для товаров без документов** (в связке со сводкой ресерчера). При наличии нормативных документов характеристика категории не передается.
2. **Агент-копирайтер (`productCharacteristicsCopywriterAgent.ts`)**:
   - Модели: `google/gemini-3.5-flash-lite`, `google/gemini-3.1-flash-lite` с ротацией ключей через `createGoogleMultiKeyAgent`.
   - Промпт: `prompts/productCharacteristicsCopywriter.md`.
3. **Агент-арбитр (`productCharacteristicsJudgeAgent.ts`)**:
   - Модели: `google/gemini-3.5-flash-lite`, `google/gemini-3.1-flash-lite`.
   - Промпт: `prompts/productCharacteristicsJudge.md`.
   - Строгий аудит числовых параметров, погрешностей, ссылок и разметки.
   - Возврат структурированного JSON (`judgeEvaluationSchema`: `PASS`/`FAIL`, критика, требуемые исправления).
4. **Агент-ресерчер (`productCharacteristicsResearcherAgent.ts`)**:
   - Модели: Flash-Lite, подключение инструментов `tavilySearch` и `tavilyExtraction`, кэширование в `LibSQLServerCache`.
   - Запуск только для товаров без нормативных документов.
