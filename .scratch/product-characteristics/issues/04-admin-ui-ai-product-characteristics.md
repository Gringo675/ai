# Issue 04: Страница управления в AdminPanel (`aiProductCharacteristics.vue`)

## Проблема
Операторам контента требуется наглядный интерфейс для генерации, визуального контроля (Было / Стало), точечной доработки и выборочного сохранения характеристик товаров выбранной категории без необходимости ручной обработки тысяч позиций с нуля.

## Требования к реализации
1. Создать страницу `app/pages/admin/cms/aiProductCharacteristics.vue` в проекте `site-wsl`.
2. Компоновка интерфейса:
   - **Шапка:** выбор категории из иерархического меню `useCats()` (поддерживаются как главные категории, так и подкатегории), кнопка пакетного запуска («Сгенерировать характеристики»).
   - **Левая колонка (Список товаров):**
     - Таблица/список товаров категории с чекбоксами для выбора.
     - Индикаторы статуса: текущее наличие ТТХ в базе, статус генерации (`PASS` — зеленый бейдж, `FAIL` — красный бейдж, `В процессе`, `Не запускался`).
     - Прогресс-бар последовательной обработки: `Обработано X из Y товаров...`.
   - **Правая колонка (Карточка выбранного товара):**
     - Заголовок с названием и ссылкой на карточку товара в каталоге.
     - Вкладки: «Сравнение (Было / Стало)», «Предпросмотр», «HTML-код».
     - Блок вердикта арбитра: отображение статуса `PASS` / `FAIL`, критики и списка замечаний.
     - Блок ревизии: текстовое поле для ввода замечаний редактора + кнопка «Перегенерировать товар» (отправка с `editorFeedback`).
   - **Тулбар сохранения:**
     - Кнопка «Сохранить выбранный товар».
     - Кнопка «Сохранить все успешные (PASS)».
     - Отправка данных на существующий эндпойнт `/api/admin/cms/products/updProds`.
3. Взаимодействие с Mastra:
   - Использование адаптера `mastraWsAdapter` для последовательного вызова воркфлоу `product-characteristics` по каждому товару.
   - Возможность отмены или паузы процесса.
