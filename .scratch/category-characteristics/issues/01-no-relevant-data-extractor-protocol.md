# 01 — Протокол отсечения нерелевантных документов (NO_RELEVANT_DATA) в экстракторе

**What to build:**
Добавить в системный промпт агента-экстрактора документов правило строгого возврата сигнальной строки `NO_RELEVANT_DATA` в ситуациях, когда в анализируемом документе (например, методике поверки или нерелевантном стандарте) отсутствуют числовые метрологические параметры, таблицы или характеристики для переданного списка целевых товаров категории. Это позволит конвейеру воркфлоу отсекать пустые и чисто процедурные документы до передачи данных копирайтеру.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] В системный промпт экстрактора добавлена строгая инструкция: если в документе нет полезных технических параметров для заданных целевых продуктов, агент возвращает исключительно строку `NO_RELEVANT_DATA` без лишних пояснений.
- [ ] Экстрактор продолжает корректно и без искажений извлекать таблицы и спецификации, когда релевантные данные для продуктов присутствуют.
